Como obter um link funcional

OneDrive Personal — método recomendado (URL Embed):
⚠️ Microsoft restringiu o acesso ao link normal de compartilhamento (retorna HTTP 401). Use o link Embed:

  1. Abra o arquivo no OneDrive web
  2. Menu ⋯ Mais opções → Inserir (ou Embed)
  3. Clique em Gerar
  4. Copie só a URL dentro de src="..." (começa com https://onedrive.live.com/embed?...)
  5. Cole aqui — o dashboard converte automaticamente embed? para download?

OneDrive Business / SharePoint: copie o link de compartilhamento e adicione ?download=1 no final. Quem abrir o dashboard precisa estar logado na conta Microsoft da empresa.

GitHub ⭐ (mais confiável — basta repositório público, não precisa GitHub Pages): Suba o Excel no repo. Cole aqui a URL github.com/usuario/repo/blob/main/arquivo.xlsx que o dashboard converte sozinho para a URL raw.githubusercontent.com (CORS aberto). Para hospedar o dashboard também, ative Settings → Pages no repo.

Cloudflare Pages / Netlify: suba o site estático e use a URL pública do Excel. Mesma lógica.

Não funciona: link https://1drv.ms/... direto (401), pasta de rede (file://), URL do "Compartilhar" do OneDrive Personal.

ℹ Como funciona
Kanban do fluxo de execução — mostra OSs sinalizadas com 📍 Na Oficina (veículos ou componentes avulsos) nas colunas operacionais (Recepção → Execução). Histórico OSs

Arquivo consultivo de OSs que saíram das abas Abertas_MECANICA / Abertas_RETIFICA em cargas anteriores. Cada entrada preserva todos os campos (Cliente, Modelo, valores P/S/T/Total, Recepção) + as anotações (vendedor, situação, aprovação, condição de pagamento). O sistema faz cruzamento automático com a base de faturamento (Sheet1) por número de OS para indicar se a OS foi faturada ou removida sem faturamento. Dados sincronizados via Firebase — todos os usuários veem o mesmo histórico.
